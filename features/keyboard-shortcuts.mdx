Speed up your workflow with keyboard shortcuts. Keep your hands on the keyboard and maintain your flow while working with Khoj.

<Note>

</Note>

## Chat Input Shortcuts

<Tabs>
  <Tab title="Obsidian" icon="o">
    Navigate your chat history without reaching for the mouse:
    
    | Shortcut | Action |
    |----------|--------|
    | <kbd>↑</kbd> Up Arrow | Move up in recent message history |
    | <kbd>↓</kbd> Down Arrow | Move down in recent message history |
    | <kbd>Enter</kbd> | Send current message |
    | <kbd>Shift</kbd> + <kbd>Enter</kbd> | New line in message |
    
    ### How Message History Works
    
    <Steps>
      <Step>Place cursor in chat input box</Step>
      <Step>Press <kbd>↑</kbd> to load your previous message</Step>
      <Step>Keep pressing <kbd>↑</kbd> to go further back</Step>
      <Step>Press <kbd>↓</kbd> to move forward in history</Step>
      <Step>Edit and send to revise your query</Step>
    </Steps>
    
    <Frame>
      <img src="https://assets.khoj.dev/up_down_shortcuts.gif" alt="Arrow key navigation demo" />
    </Frame>
    
    <Tip>
      Try it on [this sample conversation](http://app.khoj.dev/share/chat/in-particular-assess-the-prospect-for-brazil-/)
    </Tip>
  </Tab>
  
  <Tab title="Web" icon="globe">

    | <kbd>Shift</kbd> + <kbd>Enter</kbd> | New line in message |

## Custom Shortcuts

<AccordionGroup>
  <Accordion title="Obsidian Custom Hotkeys" icon="o">
    Set up your own shortcuts:
    
    <Steps>
      <Step>Open Obsidian Settings (<kbd>Cmd/Ctrl</kbd> + <kbd>,</kbd>)</Step>
      <Step>Go to **Hotkeys** section</Step>
      <Step>Search for "Khoj"</Step>
      <Step>Click the "+" next to any command</Step>
      <Step>Press your desired key combination</Step>
      <Step>Click outside to save</Step>
    </Steps>
    
    **Recommended custom hotkeys:**
    - `Khoj: Chat` → <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>
    - `Khoj: Search` → <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>
    - `Khoj: Find similar` → <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>
  </Accordion>
  
  <Accordion title="Browser Shortcuts (Web)" icon="globe">
    Create browser bookmarks with keyboard shortcuts:
    
    **Chrome/Edge:**
    1. Visit app.khoj.dev
    2. Click star icon to bookmark
    3. Right-click bookmark → Edit
    4. Can't directly assign hotkey, but use bookmark bar (<kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd>)
    
    **Firefox:**
    1. Bookmark app.khoj.dev
    2. Give it a keyword like "khoj"
    3. Type "khoj" in address bar to open quickly
  </Accordion>
  
  <Accordion title="System-Level Shortcuts" icon="desktop">
    Launch Khoj Desktop with global hotkey:
    
    **macOS:**
    1. System Settings → Keyboard → Shortcuts
    2. App Shortcuts → Add (+)
    3. Select Khoj application
    4. Assign hotkey
    
    **Windows:**
    1. Right-click Khoj shortcut
    2. Properties → Shortcut key
    3. Press desired key combination
    4. Click OK
    
    **Linux:**
    Depends on desktop environment (GNOME, KDE, etc.)
    - Usually in Keyboard Settings
    - Create custom shortcut to launch Khoj
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Shortcut not working">
    **Possible causes:**
    - Conflict with system/browser shortcuts
    - Different keyboard layout
    - Platform-specific variations
    - Feature not available on current platform
    
    **Try:**
    - Check if another app is capturing the shortcut
    - Try alternative key combination
    - Restart the application
    - Check documentation for your specific platform
  </Accordion>
  
  <Accordion title="Arrow keys not navigating messages (Obsidian)">
    **Check:**
    - Cursor is in the input box
    - No text is currently in the input
    - Khoj plugin is up to date
    - Conversation has previous messages
    
    **Try:**
    - Click in input box first
    - Clear any existing text
    - Update Khoj plugin
  </Accordion>
  
  <Accordion title="Different behavior on Mac vs Windows">
    Remember:
    - Mac uses <kbd>Cmd</kbd> where Windows uses <kbd>Ctrl</kbd>
    - Some shortcuts are OS-specific
    - Browser shortcuts may differ
    
    This guide shows **Cmd/Ctrl** to indicate the modifier key for your platform.
  </Accordion>
</AccordionGroup>
