## How Voice Chat Works

<Steps>
  <Step title="Speak Your Query">
    Click the microphone icon and talk naturally
  </Step>
  
  <Step title="Speech Recognition">
    Khoj transcribes your voice to text using speech-to-text AI
  </Step>
  
  <Step title="Review & Edit">
    The transcription appears - you can edit it before sending if needed
  </Step>
  
  <Step title="Send & Receive">
    Submit the message and receive text or voice response
  </Step>
</Steps>

## Voice Chat Tips

<AccordionGroup>
  <Accordion title="Speak Clearly" icon="microphone">
    - Use a quiet environment when possible
    - Speak at a normal pace - not too fast or slow
    - Enunciate clearly, especially for technical terms
    - Pause briefly between sentences
  </Accordion>
  
  <Accordion title="Structure Complex Queries" icon="list-ol">
    For multi-part questions, use structure:
    
    **Good:**
    ```
    "I have three questions. First, what's the weather today? 
    Second, summarize my notes from yesterday. Third, what's 
    on my calendar tomorrow?"
    ```
    
    This helps both transcription accuracy and response quality.
  </Accordion>
  
  <Accordion title="Review Before Sending" icon="eye">
    Always check the transcription:
    - Fix any misheard words
    - Add punctuation if needed
    - Correct technical terms or names
    
    This ensures Khoj understands exactly what you meant.
  </Accordion>
  
  <Accordion title="Use Voice for Long-Form" icon="paragraph">
    Voice shines for:
    - Lengthy queries or descriptions
    - Brainstorming sessions
    - When typing is inconvenient
    - Dictating notes or ideas
  </Accordion>
  
  <Accordion title="Mix Input Methods" icon="shuffle">
    Combine voice and text freely:
    - Speak your question
    - Type follow-up refinements
    - Use voice for the next topic
  </Accordion>
</AccordionGroup>

## Self-Hosting Configuration

### Speech-to-Text (Voice Input)

<Tabs>
  <Tab title="Default (Local)" icon="server">
    **Automatically configured** when you initialize Khoj.
    
    - Runs locally on your server
    - No API keys needed
    - Privacy-friendly
    - Works offline
    - Uses open-source models
    
    <Note>Default configuration is sufficient for most users</Note>
  </Tab>
  
  <Tab title="OpenAI Whisper API" icon="cloud">
    For potentially better accuracy with cloud processing:
    
    <Steps>
      <Step title="Get OpenAI API Key">
        If not already configured, get an API key from [OpenAI](https://platform.openai.com/settings/organization/api-keys)
        
        [See chat model setup →](/get-started/setup#add-chat-models)
      </Step>
      
      <Step title="Create Speech-to-Text Config">
        Navigate to: `http://localhost:42110/server/admin/database/speechtotextmodeloptions/`
        
        Click **"Add Speech to Text Model Options"**
      </Step>
      
      <Step title="Configure Model">
        - **Model name:** `whisper-1`
        - **Model type:** `Openai`
        - **AI model API:** Select your configured OpenAI API
      </Step>
      
      <Step title="Save and Restart">
        Save configuration and restart Khoj server
      </Step>
    </Steps>
    
    **Benefits:**
    - Very high accuracy
    - Supports many languages
    - Better with accents and background noise
    
    **Cost:** ~$0.006 per minute of audio
  </Tab>
</Tabs>

### Text-to-Speech (Voice Output)

<Tabs>
  <Tab title="Default (Local)" icon="server">
    **Included by default** - uses local text-to-speech.
    
    Works immediately with no configuration.
  </Tab>
  
  <Tab title="ElevenLabs" icon="microphone-lines">
    For high-quality, natural-sounding voices:
    
    <Steps>
      <Step title="Create ElevenLabs Account">
        Sign up at [elevenlabs.io](https://elevenlabs.io/)
      </Step>
      
      <Step title="Get API Key">
        Generate an API key from your ElevenLabs dashboard
      </Step>
      
      <Step title="Set Environment Variable">
        Add to your environment:
        
        ```bash
        export ELEVEN_LABS_API_KEY=your_api_key_here
        ```
        
        Or in docker-compose.yml:
        ```yaml
        environment:
          - ELEVEN_LABS_API_KEY=your_api_key_here
        ```
      </Step>
      
      <Step title="(Optional) Choose Voice">
        Browse voices at [ElevenLabs Voice Library](https://elevenlabs.io/app/voice-library)
        
        To configure a specific voice:
        1. Navigate to: `http://localhost:42110/server/admin/database/voicemodeloption/`
        2. Click **"Add Voice Model Option"**
        3. Enter the **Voice ID** from your chosen voice
        4. Save
      </Step>
      
      <Step title="Restart Server">
        Restart Khoj to apply changes
      </Step>
    </Steps>
    
    **Benefits:**
    - Extremely natural voices
    - Multiple voice options
    - Emotional intonation
    - Multiple languages
    
    **Cost:** Character-based pricing (see [ElevenLabs pricing](https://elevenlabs.io/pricing))
  </Tab>
</Tabs>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Microphone not working">
    **Browser (Web):**
    - Check browser permissions for microphone access
    - Look for blocked mic icon in address bar
    - Try a different browser
    - Ensure no other app is using the microphone
    
    **Desktop:**
    - Check system microphone permissions
    - Verify mic is selected as input device
    - Restart the application
    
    **General:**
    - Test microphone in other apps
    - Check physical mic connection
    - Update audio drivers
  </Accordion>
  
  <Accordion title="Poor transcription accuracy">
    **Improve quality:**
    - Speak more slowly and clearly
    - Use quieter environment
    - Get closer to microphone
    - Switch to OpenAI Whisper API (self-hosted)
    - Use better microphone hardware
    
    **For technical terms:**
    - Spell them out if needed
    - Edit transcription before sending
    - Add to custom vocabulary (if available)
  </Accordion>
  
  <Accordion title="No voice response">
    **Check:**
    - Voice output feature is web-only currently
    - Click speaker icon manually to play
    - Browser audio permissions granted
    - Volume not muted
    - ElevenLabs API key valid (if configured)
    
    **Self-hosted:**
    - Check server logs for TTS errors
    - Verify ELEVEN_LABS_API_KEY environment variable
    - Ensure sufficient API credits
  </Accordion>
  
  <Accordion title="Voice response cuts off">
    - Check internet connection stability
    - Try shorter messages
    - Verify browser audio isn't interrupted
    - Check API rate limits (ElevenLabs)
  </Accordion>
</AccordionGroup>

## Privacy Considerations

<Info>
  **Voice data handling:**
  
  **Local processing (default):**
  - Voice stays on your server
  - No data sent to third parties
  - Maximum privacy
  
  **Cloud APIs (OpenAI Whisper, ElevenLabs):**
  - Audio sent to API provider for processing
  - Subject to provider's privacy policies
  - Typically not stored long-term
  - Check provider terms for details
</Info>
