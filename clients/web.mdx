# Web Client

The Khoj web client is the easiest way to get started with your AI-powered second brain. Access it from any device with a web browser at [app.khoj.dev](https://app.khoj.dev).

![Khoj Web App Home](https://assets.khoj.dev/quadratic_equation_khoj_web.gif)

## Getting Started

<Steps>
  <Step title="Access Khoj Cloud">
    Navigate to [app.khoj.dev](https://app.khoj.dev) in your web browser. No installation required!
  </Step>
  
  <Step title="Sign In">
    Create an account or sign in with your existing credentials to start using Khoj.
  </Step>
  
  <Step title="Start Chatting">
    Begin asking questions or uploading documents immediately. No additional setup needed!
  </Step>
</Steps>

## Upload Documents

You can upload documents to Khoj directly from the web interface. This is particularly useful for mobile devices or when you want to quickly add a single document.

<Tabs>
  <Tab title="Drag and Drop">
    Simply drag and drop files directly into the chat window.
    
    ![Drag and drop file upload](https://assets.khoj.dev/home_page_data_upload.gif)
  </Tab>
  
  <Tab title="File Picker">
    1. Click the paperclip icon in the chat window
    2. Select the document from your file system
    3. Wait for the upload to complete
  </Tab>
</Tabs>

<Note>
  For syncing entire folders or bulk document management, consider using the [Desktop client](/clients/desktop) or [Obsidian plugin](/clients/obsidian).
</Note>

## Progressive Web App (PWA)

Install Khoj as a Progressive Web App for quick access and a native app-like experience.

### On Mobile

<Steps>
  <Step title="Open Khoj in Browser">
    Navigate to [app.khoj.dev](https://app.khoj.dev) using Chrome or Edge on your phone and sign in.
  </Step>
  
  <Step title="Open Browser Menu">
    Tap the three-dot menu in your browser.
  </Step>
  
  <Step title="Add to Home Screen">
    Select "Add to Home screen" from the menu options.
  </Step>
  
  <Step title="Install">
    Tap "Install" on the confirmation dialog to add the Khoj icon to your home screen.
  </Step>
</Steps>

### On Desktop

<Steps>
  <Step title="Open in Chrome">
    Navigate to [app.khoj.dev](https://app.khoj.dev) in Chrome or Edge.
  </Step>
  
  <Step title="Click Install Icon">
    Look for the install icon in the address bar and click it.
    
    ![PWA Install Desktop](https://assets.khoj.dev/pwa_install_desktop.png)
  </Step>
  
  <Step title="Alternative Method">
    Or use the menu:
    1. Click the three-dot menu in the top right
    2. Go to 'Cast, Save, and Share'
    3. Click "Install Khoj" or "Open in Khoj"
    
    ![Chrome PWA Alternative](https://assets.khoj.dev/chrome_pwa_alt.png)
  </Step>
</Steps>

<Tip>
  You must be logged into your Chrome browser for PWA installation to work on desktop.
</Tip>

## Self-Hosting

If you're running your own Khoj server, simply navigate to your server's URL instead of app.khoj.dev.

<CodeGroup>
```bash Default Local URL
http://127.0.0.1:42110
```

```bash Custom URL
http://your-server-domain:port
```
</CodeGroup>

<Note>
  The web interface works the same whether you're using Khoj Cloud or self-hosting. All features are available in both configurations.
</Note>
